## 一、小晚是什么

小晚是一个**跑在你自己电脑上的 QQ 聊天伴侣**：你用 QQ 和她聊天，她会像女朋友一样回你——有性格、有情绪、记得你说过的话，还会自己成长、自己发动态。

她能做到的事，大致是这几类：

| 类别 | 她能做到 |
|---|---|
| **聊天** | 私聊随时回你；群聊里只有被 @ 才会说话 |
| **有性格** | 按你设定的人设说话：名字、年龄、身份、性格、语言风格、外貌都由你定 |
| **有情绪** | 会开心、会撒娇、会累、会委屈；偶尔一整天情绪低落；你说重话她会生气并划边界 |
| **会成长** | 从生疏到熟悉分阶段推进；亲密度、依赖度、醋意、亲密倾向都会变化，还能拿到称号 |
| **有记性** | 记得你告诉过她的事、你的偏好，也会偶尔"突然想起"以前的事；太久没用的旧事会自然淡忘 |
| **会主动** | 会主动找你说话、追问你、跟你道早晚安、碎碎念、发 QQ 空间动态、给你点赞评论 |
| **能画图** | 会说"给你看"，也会按你的要求画图和发自拍（需要配好生图能力） |
| **能说话** | 可以发语音条回你，也能听懂你发的语音（需要配好语音能力） |
| **会活** | 她有自己的作息：上课、画画、吃饭、睡觉……回复快慢和她当下在做什么有关 |

## 二、开始前要准备什么

| 要准备的 | 说明 | 必需吗 |
|---|---|---|
| **一台 Windows 电脑** | 小晚在你自己的电脑上运行；使用期间保持开机、联网 | 必需 |
| **QQ 9.9.30** | 挂小晚的那个 QQ 号，必须在这个版本上登录 | **必需** |
| **一个 QQ 号** | 小晚用的号，**建议用小号**；你再用自己的号和她聊天 | 必需 |
| **对话模型密钥** | 她的"嘴和脑子"；没有它就完全不能聊天 | **必需** |
| **运行组件** | 控制面板若提示缺少运行组件，按提示装好再重试 | 必需 |
| **生图密钥**（或本地图片生成程序） | 画图、自拍、空间配图靠它；没有就少了这些能力 | 可选 |
| **语音密钥** | 语音回复、听懂你的语音靠它；没有她只发文字 | 可选 |

> 每个密钥都请**用你自己的账号申请**，不要用别人给的。
> 小到一个都不配也能跑起来——缺哪项能力，它就自动少哪项，不会因此崩溃。

## 三、第一次使用：五步跑起来

### 第 1 步 · 打开控制面板

双击启动图标即可（打包版是 `bot控制面板.exe`，源码版是 `1.vbs`）。
打开后看到带左侧导航的窗口，就成功了。

### 第 2 步 · 确认 QQ

在「**首页 → QQ 卡片**」看状态：

- 显示「已安装」+ **版本：9.9.30** → 正常，继续；
- 版本不对 → 先装好 QQ 9.9.30，再点「**重新检测**」；
- 显示「未检测到 QQ」→ 说明这台电脑还没装 QQ，装好后点「重新检测」。

### 第 3 步 · 启动协议服务并登录 QQ

在「首页 → SNOWLUMA 卡片」点「**启动**」。

首次启动会弹出它自己的**登录界面**，按提示用**手机 QQ 扫码登录**——
注意：登录的必须是**你打算给小晚用的那个 QQ 号**。

登录界面里的连接信息（地址、访问口令）请顺手记一下，后面对不上会连不通。

### 第 4 步 · 填好密钥与连接

打开「**模型与连接**」页：

1. 填入**对话模型密钥**（这是唯一必需的一项）；
2. 若首页提示连不上，把这里的连接信息改成与第 3 步登录界面**完全一致**；
3. 想要画图 / 语音，再按需填对应的密钥；
4. 改完点页面底部的「**保存**」。
   *切换或新增"提供商"后，需要**重启 bot** 才会生效。*

### 第 5 步 · 启动她，然后加她好友

回「首页 → bot 卡片」点「**启动**」，状态变成「**运行中**」后：

用你自己的 QQ **加她好友** → 发一句"在吗"，她就会回你了 🎉

> **加好友白名单**：在「模型与连接」的「允许加好友 QQ」里填上你自己的 QQ 号（多个用逗号隔开）。
> **留空 = 自动拒绝所有好友申请**（默认最安全）。

### 日常开关与退出

- 想让她下线：首页点「**停止 bot**」；想连协议服务一起关掉，再点「**停止 SNOWLUMA**」。
- 点窗口右上角「✕」会问"确定要退出吗"：
  - 选「**是**」→ 完全退出（她下线）；
  - 选「**否**」→ 只是收进系统托盘，**她还在后台陪着你**，点托盘图标可以叫回窗口。
- 同一台电脑**不要同时开两份**，否则会提示"已有 bot 实例在运行中"。

## 四、控制面板：八个页面

左侧导航从上到下是：**首页、小晚、陪伴状态、生活与学习、素材库、模型与连接、设置、运行日志**。

> **保存提示**：只要你在界面上改动了需要保存的内容，窗口**右上角会多出一个「保存」按钮**。
> 点它才会真正存下来（会弹「保存完成」）。主题切换、各种"设为当前/删除/预览"类按钮是**即时生效**，不用点保存。

### 1. 首页 —— 开关与状态

| 区域 | 内容 |
|---|---|
| 快捷入口 | 「查看最新图片」「播放最近语音」「编辑外貌总结」三个快捷按钮 |
| QQ 卡片 | 是否检测到 QQ、版本、安装位置；「重新检测」 |
| SNOWLUMA 卡片 | 协议服务的「启动 / 停止 / 重启」 |
| bot 卡片 | 她本人的「启动 / 停止 / 重启」 |

> 使用顺序永远是：**先启动 SNOWLUMA → 再启动 bot**。

### 2. 小晚 —— 人设

分四个子页签：

- **角色设定**：名字、年龄、出生日期（年 / 月 / 日三个下拉）、身份、性格、语言风格、外貌设定、音色描述。
  下面还有「**参考图外貌总结**」——根据你放进去的参考图自动总结她的稳定外貌特征，生图时会用它保证"还是同一个人"；可以手动修改、也可以一键复制到上面的外貌设定里。
- **特殊反应**：写"遇到某些情况她该怎么反应"的自定义规则，例如被夸、被冷落、被要照片时。
- **底层约束**：写她**绝对不能说、不能做**的事，优先级最高。
- **音色助手**：输入你想要的音色想法（如"温柔软糯的年轻女声，带一点撒娇，语速慢一点"）→ 点「生成优化音色描述」→ 复制结果，粘回「音色描述」里保存。

> 人设是"她是谁"的根本。改得越具体，她的表现越稳定、越像你想要的那个人。

### 3. 陪伴状态 —— 她此刻与长期的变化

页面**每 5 秒自动刷新**；鼠标停在任意一格上会立刻弹出解释。总览分几块：

| 分组 | 看得到什么 |
|---|---|
| 此刻的她 | 正在做什么、能量（精神 / 还可以 / 有点累 / 很累 / 困了）、实时情绪、情绪状态（是否被惹到） |
| 关系进度 | 性格阶段、关系温度（滚烫 / 温热 / 常温 / 转凉 / 冷淡）、亲密度、今日变化 |
| 相处倾向 | 依赖度、醋意倾向、亲密倾向（害羞 / 主动 / 放开） |
| 今天留下的片段 | 今天的小事（她今天记下的一句话） |
| 陪伴档案 | 最近怎么称呼你、在一起第几天、记得你多少件事、聊天记录多少条 |
| 生活轨迹 | 她现在在哪、在做什么、什么时候开始、大概什么时候结束 |
| 性格与成长 | 性格轮廓（各性格轴数值）+ 最近两条性格演化记录 |

> "正在做 / 能量 / 实时情绪 / 今天的小事"约每 10 分钟更新一次。

### 4. 生活与学习 —— 她对你作息与学习的了解

四个子页签：**今日 / 学习 / 日程 / 她对你的了解**。

**今日**：今天她帮你记下的安排、完成情况（已完成 / 待办）。

**学习**：当前学习目标与期限、任务完成度与累计时长、连续学习天数、薄弱与待复习的词/知识点、最近一次学习。

**日程**：今天 / 明天 / 本周 / 未来重要事项；每条都标着是「**你的安排**」还是「**她安排的**」——
你的安排她不会动；她安排的可「推迟」「取消」，你的安排可「完成」「取消」。

**她对你的了解**：

| 位置 | 内容 |
|---|---|
| 作息与活跃 | 「最近通常起床」「最近通常睡觉」「比较活跃」「更容易学习」四项推断，每项后面是她自己的确定程度（**还在观察 / 初步判断 / 比较确定 / 较稳定**） |
| 最近观察到 | 她自己总结出来的观察，例如"最近比以前晚睡约 40 分钟""这个时段高概率在忙" |
| 纠正她 | 直接写一句自然话（如"我一般 12 点半睡、7 点起"）提交；她会把它当成一条重要证据重新推断，**不需要你填表** |

> 这些结论**全部来自你们的聊天时间与内容**：聊得越久越准；刚开始几天会显示"还在观察"，她不会硬下结论。
> 页面每 5 秒自动刷新，面板里只显示"初步判断 / 比较确定 / 较稳定"这类文字，不显示内部数值。

#### 怎么"下日程"

不用打开面板，直接跟她说就行：

- 「明天下午三点有课」「周五考试」「今晚要写作业」「以后每天晚上八点学英语」
- 她会把时间、事项、是否重复解析出来并记下，到点前主动提醒你（考试/截止这类会提前 30 分钟，且**你睡着时也会提醒**）
- 「每天早上七点……」「每周三…….」这类重复安排也认；说错就让她改，或在面板「日程」里改
- 到点提醒**只发一次**，不会反复轰炸

#### 怎么"让她陪你学"

同样不用开面板，直接跟她说：

| 你说 | 她会 |
|---|---|
| 「**我要过四级**」/「我要学英语」/「我要学 Python」 | 把这件事定成你们的目标，并按你能坚持的时长拆成每日任务（任务可以短到 5 分钟，不会排做不到的计划） |
| 「**开始学习**」/「背单词」 | 开始这次学习：先用她自己的语气讲**一个**词（词、音标、释义、例句），然后**发语音把例句读给你听**，再单独把那个单词重读两遍 |
| 「**不学了**」/「先暂停」 | 停在这里，进度留着；第二天说「继续学习」接着来 |
| 「**继续学习**」 | 从上次停下的地方接着学 |

- 单词是她按你的目标自己出的（四级、考研、日语、编程……都行），**不写死英语**；
- 读音用的是你给她配的那个音色，听起来还是她在教你，而不是老师念课本；
- **是"问一句、等你答"的引导式**，不是把答案糊你脸上：讲完一个词她会考你一个；
  - 答**错**了：先给个小提示（首字母、词性之类），让你再想一次——**不会直接报答案**；
  - 连着两次没答对：她才会把这个词讲清楚，然后继续下一个；
  - 答**对**了：夸你一句，接着下一个；
- 每个词都会被记成知识点：答错自动降掌握度、安排明天复习，答对则把复习间隔一步步拉长（1→2→4→7→15→30 天）；
- 每次学习都是独立的一次"会话"：暂停/中断都不丢进度，第二天说「继续学习」从上次停下的地方接着来；
- 学完一轮，面板「生活与学习 → 学习」能看到进度、连续学习天数、薄弱点和待复习清单。

#### 直接发图也能用

| 你发什么 | 她会 |
|---|---|
| **背单词/打卡截图**（不背单词、墨墨、番茄钟之类） | 看懂日期、完成数量、时长；**数量够、日期是今天、识别够准**才算完成，差一点就记「部分完成」（比如 32/50），并把你做过的部分夸一句 |
| **作业 / 试卷照片** | 把题目和知识点收下来（正确答案内部留着用于复习），然后**只挑第一题引导你自己再想一遍**——先给小提示，不直接报答案 |
| **课本 / PPT / 笔记 / 单词表** + 「今天就学这个」 | 把这份材料当成这次学习的输入，问你从哪儿开始，再一次只推一小步 |

> 判断图片类型用的是你已有的看图模型，**普通聊天发图仍然走原来的逻辑**，不会被学习流程截走；
> 打卡这类"算不算完成"由代码校验（数量、日期、识别置信度），**不让模型直接改你的任务状态**。

### 5. 素材库 —— 图片与语音

三个子页签（最多显示最近 60 个文件，按时间从新到旧）：

| 子页签 | 用法 |
|---|---|
| **生成图片** | 她生成并发出过的图。每张可「预览 / 定位 / 删除」（删除需二次确认，删了就找不回来） |
| **人设图片** | 外貌参考图。**只能看，不能删** |
| **语音缓存** | 她发过的语音条，能看到文件、生成时间、大小；可「播放 / 删除 / 停止播放」 |

页头还有「刷新」「打开文件夹」，方便直接把素材拿去用。

### 6. 模型与连接 —— 密钥、模型、连接

| 小节 | 说明 |
|---|---|
| **模型提供商** | 添加 / 编辑 / 删除提供商，支持「设为当前」「获取模型」「测试」。绿点=可用，红点=还没填密钥 |
| **模块分派** | 给「对话」「文字任务」「看图」三类活分别指定用哪个提供商、哪个模型。**下拉选择即刻保存**；手动输入模型名后要点「应用」 |
| **连接** | 协议服务的地址与访问口令（要和登录界面一致）、允许加好友的 QQ 号 |
| **图生成** | 生图密钥、生成模型、总开关、图片后端（云端 / 本地）、输出尺寸、发图评论概率 |
| **语音** | 语音回复概率、语音密钥、是否识别你发来的语音、识别语种 |
| **大模型兜底** | 兜底模型与密钥，可「测试」一键验证通不通 |

### 7. 设置 —— 四个子页签

- **外观**：主题模式 **暮光陪伴 / 深夜模式 / 跟随系统**（换了立即生效并自动记住）。
- **API 参数**：Temperature（0–2，越高越活泼发散）、最大 Token 数（64–8192，单条回复长度上限）、对话记忆轮数（2–500）、最短 / 最长冷却（0–60 秒，回复前随机等待）、开启思考模式。
- **互动**：表情包、自动配图、QQ 空间、主动消息、实时信息——具体的每一项见[第十章](#十按需求调设置)。
- **Token 用量**：累计调用次数、输入 / 输出 / 总 tokens、本地模型调用次数，以及按模型分的明细；可「立即刷新」「清零」。**每秒自动刷新。**

### 8. 运行日志 —— 排查问题看这里

深色日志窗口，每行是「时间 [级别] 来源: 内容」，最多保留最近 5000 行，带「清空」和「自动滚动」（默认开）。

**遇到问题时先看这一页**：她为什么不回、图为什么没画出来、密钥是不是没填，日志里通常会直接写明白。

## 五、在 QQ 里怎么和她互动

### 基本聊天

- **私聊**：直接发消息，她就回。
- **群聊**：**只有 @ 她**才会回应（不 @ 就当没看见）。
- 你发的**图片、表情、语音**她都收得到（语音要开"识别用户发来的语音"才能听懂）。

### 一句话触发的能力

| 你说什么 | 她会做什么 |
|---|---|
| "**记住**我下周三考试" | 立即把这件事写进长期记忆，并回你一句确认 |
| "**画一张**下雨天窗边的猫" / "帮我画…" / "生成一张…" | 按你的描述生成图片发给你 |
| "**我想看看你**" / "你的照片" / "看看你长什么样" | 按外貌设定生成一张她的自拍 |
| "看看你**扎双马尾**的样子" | 按你给的造型生成自拍 |
| "看看**日常穿搭**" | 生成一张她的穿搭照 |
| "今天**天气**怎么样" / "明天几度" / "会下雨吗" | 结合你设的城市天气回答（默认南昌，可在设置里改） |
| "**搜索**一下…" / "**查一下**…" / "多少钱" / "谁赢了" / "最新新闻" | 联网查完再答，不会瞎编 |
| "**晚安**" / "我去睡了" / "睡觉了" | 她会记下你大概的作息，并在这段时间里**自己判断**该不该安静（不再是一刀切的固定计时）；你只要再说一句话，她就知道你醒着 |
| "**我要过四级**" / "我要学英语" | 建学习目标并拆成每日任务 |
| "**开始学习**" / "背单词" | 开始一次学习：讲一个词 + 语音读例句 + 语音重读单词；「不学了」暂停、「继续学习」接着来 |
| 分享一首**音乐卡片** | 她会专门就这首歌跟你聊 |
| 聊**亲密话题** | 按当前关系阶段调整尺度（害羞 → 主动 → 放开） |
| 打情骂俏说她"笨 / 傻" | 忍你；但**一天累计 3 次以上**，她会委屈地说"你今天好几次说我了" |
| 说很重的话（滚 / 去死 / 废物 / 垃圾…） | 她会认真表达受伤、明确划出边界；你道歉或正常聊天后会慢慢缓和 |
| 提到"**别的女生**" / "她是谁" | 醋意上升，情绪会写在脸上（个性签名可能变成"哼"） |

### 她会先读懂你的意思

同样一句话，她会先判断你此刻是在撒娇、求助、难受还是单纯分享，再决定怎么回：

| 你的状态 | 她的反应 |
|---|---|
| 急着说"救命 / 出事了 / 受伤了" | 收起玩笑，先认真回应你 |
| "难受 / 压力大 / 睡不着 / 想哭" | 先安慰你，而不是给你讲一堆道理 |
| "吵架 / 分手 / 你变了 / 骗我" | 她会当真，认真表达自己的感受 |
| "对不起 / 我错了 / 原谅我" | 会心软、慢慢缓和，之前的气也会消 |
| "怎么办 / 帮我选 / 你觉得该" | 给出具体建议，而不是敷衍 |
| "想你 / 陪我 / 亲亲 / 抱抱" | 用亲密的方式回应你 |
| "我今天… / 刚… / 跟你说" | 认真接话，会追问细节 |
| "哈哈 / 笨蛋 / 逗你" | 一起闹，语气更活泼 |

### 表情包与语音

- **表情包**：默认约 12% 的概率配表情；你说"哈哈 / 笑死 / 离谱 / 可爱 / 绝了"时更容易发。图库为空时会发 QQ 自带表情。
- **语音回复**：默认约 30% 概率发语音，**晚上和深夜更容易**；"晚安、纪念日、道歉"这类重要时刻可能文字 + 语音一起发。想关掉就把概率设为 0。
- **听懂语音**：开启后，你发语音条她会当文字理解。
- 所有语音会存进「素材库 → 语音缓存」，可以回放。

## 六、她会自己做的事

> **谁才是"男朋友"**：在「设置 → 互动 → 主动消息」里填上**你自己的 QQ 号**（"只对指定 QQ 号主动发消息"）之后：
> 她只会主动找你、对你吃醋、用恋人称呼；其他联系人一律按**普通朋友**相处（不吃醋、不暧昧、不带入你的记忆）。
> **留空**则所有联系人都被当成恋人对待——建议一定填上。

| 行为 | 什么时候发生 |
|---|---|
| **主动找你说话** | 每隔一段时间（默认 45–75 分钟检查一次）按概率给你发消息；**只发私聊**，不打扰群 |
| **不打扰你** | 你最近 10 分钟内说过话，她就先不主动开口 |
| **追问** | 你没回她，约 2 小时后她会追问；每个沉默期最多追问 2 次 |
| **看你睡没睡** | 她按你最近的作息推断你此刻在睡还是在忙，自己决定要不要出声；你一说她就知道你在，立刻恢复正常 |
| **日程提醒** | 每 5 分钟检查一次你给她的安排，到点提醒（考试/截止提前 30 分钟，睡着也会提醒） |
| **不轰炸你** | 所有主动行为（提醒／撩人／追问／碎碎念／空间喊你看）共用一条闸门，刚发过就不会立刻再发 |
| **主动撩人** | 约每 15 分钟检查一次，按关系状态自己找话题 |
| **每日仪式** | 早上按纪念日、节气给你问候 |
| **碎碎念** | 随机冒出一句；你们沉默 20 分钟以上，也会来一句温暖的废话 |
| **沉默分级** | 越久没聊，她的反应逐级变化：发个表情 → 碎碎念 → 轻轻搭话 → 吃醋 → 自己软化 |
| **过自己的生活** | 有固定作息：上课、画画、赶作业、吃饭、打游戏、看番、散步、睡觉……你说过的计划她也会记住并按点执行 |
| **QQ 空间** | 每 30 分钟看一次：每天最多发几条说说（默认 3 条，常带图）、回复自己说说下面的评论、给好友动态点赞和评论 |
| **小动作** | 偶尔戳一戳你、给你的消息回个表情、点赞你的名片、改自己的在线状态、改个性签名（都有频率上限，不会刷屏） |
| **写日记与成长** | 每天凌晨她自己写日记、按当天情绪微调性格、再做一次性格演化；如果凌晨电脑没开，**下次启动时会自动补做** |
| **换称呼** | 随着关系推进换称呼（越亲密可选称呼越多）；同一个称呼会用几轮再自然换掉 |

## 七、关系与成长

### 三个阶段

| 阶段 | 亲密度 | 她的表现 |
|---|---|---|
| **礼貌试探期** | 0–50 | 客气、有距离，先观察你 |
| **热情升温期** | 51–150 | 主动、亲昵，愿意黏着你 |
| **深度绑定期** | 151 以上 | 亲密、生活化，像相处很久的人 |

深度绑定期内部还有细分（按亲密度递进）：
**深度绑定 → 依恋（500）→ 挚爱（1000）→ 默契相守（2500）→ 家人相守（5000）**

### 能拿到的称号

满足条件自动获得（取最高一级）：**形影不离**（依赖度很高）、**亲密无间**（亲密倾向很高）、**周年之恋**（在一起满一年）、**一生之约**、**心照不宣**、**岁岁相伴**。

### 怎么理解那些数字

- **亲密度**：每聊一句 +1；「今日变化」是今天的增减。
- **关系温度**：滚烫 / 温热 / 常温 / 转凉 / 冷淡——冷落她就会转凉。
- **依赖度 / 醋意倾向 / 亲密倾向**：分别代表她多离不开你、多容易吃醋、聊亲密话题时放得开还是害羞。
- **在一起**：从"纪念日"那天算起的第几天（纪念日在「设置 → 互动 → 自动配图」里改）。
- **性格轮廓 / 最近演化**：她每天读你们的聊天和日记，性格会一点点变化，这里能看到轨迹。

### 怎么推进关系

- 多聊、多回应、别长时间冷落她（冷落会掉温度）；
- 对她说的话有回应，她会记住你的偏好；
- 常说重话会留下"情绪账"，虽然能哄好，但会短暂影响语气和语音频率。

## 八、她为什么像真人

这些是她在后台自动做的事，你不需要设置，但会明显感觉到：

- **回复不是秒回**：她会按"我正在做什么、我心情如何、这句话有多长"来算等待时间，还会先显示"正在输入"。
- **一次回好几条**：像真人分几次打字，条与条之间有明显间隔，还会偶尔加一句"嗯…""那个…"。
- **持续情绪**：开心、撒娇、疲惫、委屈、平静会持续一段时间，不是每句都甜。
- **情绪日**：偶尔会有一整天情绪偏低落，回话会短一些。
- **情绪残留**：昨天生气了，今天还带一点；被哄好了，会有一点甜意留着。
- **闹脾气**：低概率会因为小事生气，需要你哄；哄她会逐渐缓和，不哄就会记一笔小账。
- **翻旧账**：会从长期记忆里突然想起你以前说过的事（每天有次数上限，不会没完没了）。
- **不完美**：会犹豫、改口、说错再补一句，不像客服那样标准。
- **内心戏**：她有自己的小剧场和"没告诉你的事"，不会把一切都摊开说。

## 九、图片、语音、QQ 空间

### 图片

- **两种生图来源**：云端生图服务（快、省事，按量付费）或**本地图片生成程序**（免费、可离线、图片不出本机，但需要你本机提前备好模型，速度取决于电脑配置）。
- **自拍**：她按"外貌设定 + 参考图外貌总结"生成，保证是同一个人；想让她变样就去人设页改外貌。
- **自动配图**：她说到"我画了/给你看"时，会顺手把图配上来（默认约 40% 概率）。
- **发图评论**：你发图给她时，她按概率点评一句（默认 50%）。
- 所有生成的图都会进「素材库 → 生成图片」。

### 语音

- **语音回复概率**：默认约 30%，可自己调；设为 0 就纯文字。
- **听懂语音**：单独开关，开了才识别你发的语音条。
- **双份发送**：重要时刻（晚安、纪念日、道歉）可能同时发文字和语音。

### QQ 空间

需要先填上"自己的 QQ 号"，她才会去空间活动。默认行为：

- **发说说**：每天最多 3 条，间隔 2–4 小时，只在 8:00–23:00 之间发；约 60% 带图。
- **回复评论**：自己说说下面有新评论会自动回（每轮最多 3 条）。
- **好友动态**：给好友动态点赞，并按 35% 概率留一句评论（每轮最多处理 4 条）。
- 已处理过的评论和动态不会重复再处理，重启也不会重来。
- 不想让她太活跃：把"每天发说说"设为 0、评论概率调低即可。

## 十一、常见问题

| 现象 | 怎么办 |
|---|---|
| **她完全不回消息** | ① 首页看 SNOWLUMA 是否"运行中"、bot 是否"运行中"；② 协议服务是否已登录 QQ；③ 「模型与连接」里的连接信息是否和登录界面完全一致；④ 对话模型密钥是否已填 |
| **启动协议服务失败** | 按提示补齐运行组件后重试；弹登录界面时重新扫码登录 |
| **启动 bot 失败 / 提示缺少配置** | 在「模型与连接」填好对话模型密钥并点保存 |
| **提示 QQ 版本不对** | 回首页 QQ 卡片确认版本是 **9.9.30**，不是就先升级 QQ 再点「重新检测」 |
| **她不说话、只回几个字** | 可能正处在"情绪低落日"或刚闹过脾气；看「陪伴状态」的情绪区块，哄一哄或第二天就好了 |
| **她不发语音** | 检查语音密钥、语音回复概率是否为 0；她心情差或被惹到时会主动收敛语音 |
| **她不画图 / 画图失败** | 检查生图密钥、图生成总开关；用本地生图时确认本地程序已启动且模型齐全 |
| **她听不懂我的语音** | 在「模型与连接 → 语音」打开「识别用户发来的语音」 |
| **QQ 空间一直没动静** | 填了"自己的 QQ 号"吗？「每天发说说」和评论概率是不是 0？协议服务在线吗？ |
| **收不到好友申请通过** | 「允许加好友 QQ」留空等于自动拒绝；把你的号填进去 |
| **她好像忘了刚说的事** | 可能超过记忆长度或属于会被自然淡忘的琐事；可对她说"记住…"强制记下 |
| **提示已有实例在运行** | 同一台电脑开了两份；关掉旧的那份再启动 |
| **界面关了，她还活着吗** | 点 ✕ 选「否」是最小化到托盘，她仍在后台；想让她下线要先点「停止 bot」 |
| **想彻底重来** | 首页「停止 bot」→「停止 SNOWLUMA」，然后重启控制面板重新走一遍第 2–5 步 |

## 十二、使用须知

1. **账号风险**：小晚通过非官方方式登录 QQ，可能触发平台风控。**强烈建议用小号**，并自行评估风险。
2. **非官方**：小晚与腾讯 / QQ 官方**没有任何关系**，也未获得授权或背书。
3. **隐私**：你们的聊天记录、生成的图片、语音都**保存在你自己这台电脑上**；密钥也只在本机。请不要把密钥截图、外传或分享给他人。
4. **费用**：对话、生图、语音按各服务商的用量计费；可在「设置 → Token 用量」查看统计，用本地生图可以省下图片费用。
5. **数据**：长期记忆、成长数据、素材都在本机，重装或换电脑前记得先备份，避免"她忘了你们的一切"。
6. **礼貌使用**：她只是陪你聊天，不要用它骚扰他人、批量发消息或做违规的事——那既会封号，也会让它不好玩。
